# 輪郭選別器 — 実装計画

作成: 2026-09-23
前提: [`marigold_v2_transfer_results.md`](marigold_v2_transfer_results.md) §4

---

## 0. 解く問題

SAM の輪郭画素のうち **79.8% は深度の段差が無い場所**にある。
そこで「±2px の帯を捨てて埋め直す」操作をすれば滑らかな面を壊すだけで、
これが鋭化が Marigold V2 で −1.90% になる原因である。

位置精度は足りている（真の段差から最寄りの輪郭まで中央値 1.00px）。
**必要なのは「この輪郭画素に深度の段差があるか」の判定器である。**

| | 生の BF1 増分 |
|---|---:|
| 選別なし | **−1.90%** |
| オラクル選別（GT で 1px 以内に絞る、位置精度は同じ） | **+43.39%** |

45pt の幅がある。**そこそこの選別器でも正に届く余地が広い。**

## 1. 疎さの交絡 — 既に排除されている（改訂）

初版は「オラクル選別が輪郭を 4.0% に減らすので、選別の質ではなく疎であること自体が
効いているのではないか」を最優先の対照に据えた。**これは既存の測定で答えが出ていた。**

移設対照 `yolo_ctrl` の実装は `np.roll(cont, (dy, dx))` であり、
**画素数も形状もそのままに場所だけを動かす**。つまり「同じ疎さ、違う場所」である。

| | 生 | 移設対照（同じ疎さ・違う場所） |
|---|---:|---:|
| SAM 全輪郭 | −1.90% | −6.22% |
| **オラクル選別 k=1px（4.0%）** | **+43.39%** | **−0.50%** |

4.0% の疎さのまま場所を動かすと −0.50% にしかならない。
**効果は疎さではなく「正しい場所にあること」から来ている。**

### それでも要る対照 — 無技能の選別器

排除されたのは「疎さそのもの」であって、**「SAM 輪郭の上にランダムに 4% 残した場合」**
ではない。移設対照は輪郭を SAM 輪郭から**外す**ので真の段差に当たる率がほぼ 0 になるが、
ランダム部分集合は SAM 輪郭上に留まるので約 20% は当たる。

これは**技能ゼロの選別器が到達する床**であり、学習した選別器はこれを明確に上回る必要がある。
全 Phase で残存率を揃えて並走させる。コストは輪郭キャッシュ 1 本と鋭化 1 回で約 30 分。

## 2. 信号は存在するか（Phase 0）

選別器を作る前に、**判定に使える情報がそもそも画像側にあるか**を測る。

各輪郭画素について、ラベルを「GT の深度不連続から 1px 以内か」とし、
候補特徴量ごとに AUC を測る。学習は不要、既存の NYUv2 654 枚で済む。

### 候補特徴量

| 特徴 | 根拠 |
|---|---|
| 輪郭法線方向の**予測深度の勾配** | モデルが既に段差を（鈍くとも）認識していれば勾配が立つ |
| 同・RGB の勾配 | 色の境界は深度境界と相関する（ただし RGB エッジ単独は失敗済み） |
| 予測深度の局所分散（帯の両側） | 段差があれば両側の分布が分かれる |
| 輪郭の長さ・閉曲線かどうか | 物体の外形は段差になりやすく、内部の模様はなりにくい |
| 近傍の輪郭密度 | 密集は模様、孤立は物体境界 |
| SAM のマスク面積 | 小さすぎるマスクは模様の可能性 |

### ゲート

| 結果 | 行動 |
|---|---|
| 単独で AUC ≥ 0.65、または組み合わせで ≥ 0.75 | Phase 1 へ |
| すべて 0.6 未満 | **情報が無い。** 画像側の信号だけでは判定できないので、方針を再考 |

**注意**: `load_or_build_masks` はキャッシュが無いと YOLO へフォールバックするが、
鋭化スクリプトは `yolo=None` を渡すので `AttributeError` で止まる。
**黙って飛ばされはしない**ので、train 側の輪郭は事前生成すれば足りる。

**注意**: SAM の `stability_score` と `predicted_iou` は現行キャッシュ
（`packed` + `n` のみ）に保存されていない。使うなら再生成が要る。
Phase 0 では使わず、有望なら後で足す。

## 3. 学習データ（Phase 1）

### 3.1 第一選択は NYUv2 train

| | 枚数 | シーン | test との重複 |
|---|---:|---:|---:|
| NYUv2 train | **795** | 249 | **0** |
| NYUv2 test | 654 | 215 | — |

シーン重複ゼロなので、**そのまま zero-shot に近い評価になる。**

必要な前処理は 2 つだけで、どちらも安い。

| | 内容 | 時間 |
|---|---|---|
| SAM auto48 輪郭 | test 654 枚と同じ設定で train 795 枚（実測 2.9 秒/枚） | **0.6 時間** |
| Marigold V2 予測 | 795 × 0.72 秒 | **10 分** |

輪郭画素は valid 内で **1 枚あたり 22,043**（実測）なので、**795 枚で約 1,750 万の教師ラベル**。
小さいモデルには十分である。

### 3.2 Hypersim は第二段階

`D:/lotus/data/hypersim_sam_seg/` に 59,543 枚の SAM マスクが既にあるが、
**生成方式が違う**（YOLO の bbox をプロンプトにしたもの。NYUv2 側は全体分割の automatic）。
分布が異なるので、そのまま学習データにすると転移しない恐れがある。

Hypersim を使うなら automatic モードで再生成が要り、加えて Marigold V2 の予測も要る
（59,543 × 0.72 秒 ＝ **11.9 時間**）。**Phase 2 が成功してから判断する。**

## 4. 選別器（Phase 2）

### 4.1 まず勾配ブースティング

Phase 0 の特徴量をそのまま使う。学習は数分。

**CNN より先にこれを撃つ理由**は、特徴量の寄与が見えることと、
失敗したときに「情報が無い」のか「モデルが足りない」のかを切り分けられることにある。

### 4.2 CNN は必要なら

入力 5ch（RGB 3 ＋ 予測深度 1 ＋ 輪郭マスク 1）、出力 1ch の確率。
損失は輪郭画素のみに掛ける（マスク付き BCE）。小さな U-Net で足りる見込み。

## 5. 評価（全 Phase 共通）

### 5.1 二段階で見る

| 段階 | 指標 |
|---|---|
| 選別器そのもの | precision / recall / AUC。オラクル選別との一致率 |
| **端から端まで** | 鋭化を通した **BF1**。移設対照 ＋ **同率ランダム対照** |

### 5.2 判定基準（着手前に固定）

**「生」がベースラインを上回ることを必須条件とする。**
[`marigold_v2_transfer_results.md`](marigold_v2_transfer_results.md) §3.3 で、
「正味」は生が正のときしか改善を追わないことが判明したため。

| 生の BF1 増分 | 判定 |
|---|---|
| ≥ +10% かつ 同率ランダム対照を 2 倍以上上回る | **成功。** 修論の主結果になる |
| +3〜10% | 部分的成功。閾値掃引と特徴量追加で伸ばす |
| ≤ 0% | **失敗。** 選別器の経路を閉じる |

選別器は確率を出すので、**閾値を掃引して BF1 の曲線を出す**。
残存率と BF1 の関係が、オラクルの 4.0% / +43.39% にどこまで近づくかを見る。

## 6. 段取りとコスト

| Phase | 内容 | 時間 | 中止条件 |
|---|---|---|---|
| **0a** | **同率ランダム対照（SAM 輪郭上）** | **30 分** | ランダムで +43% 近く出たら中止 |
| 0b | 特徴量の AUC | 2 時間 | 全特徴が AUC 0.6 未満なら中止 |
| 1 | NYUv2 train 795 枚の輪郭と予測 | **50 分**（輪郭 0.6h ＋ 推論 10 分） | — |
| 2 | 勾配ブースティング ＋ 端から端まで評価 | 1 日 | 生 ≤ 0 なら中止 |
| 3 | CNN（必要なら） | 2 日 | — |
| 4 | Hypersim へ拡大（成功時のみ） | 1 日 ＋ 推論 11.9 時間 | — |

**Phase 0a から始める。** ただし §1 のとおり方針の生死はすでに大きく傾いており、
0a は「学習器が超えるべき床」を定める作業である。

Phase 1 が半日から 50 分に縮んだので、**0a・0b・1 をまとめて 3 時間ほどで抜けられる。**

## 7. 既知のリスク

| | 内容 |
|---|---|
| ~~疎であることの交絡~~ | **排除済み**（§1）。移設対照が同じ疎さで −0.50% |
| **循環** | オラクル選別は GT の深度不連続で選び、BF1 も GT の深度不連続で採点する。学習器は GT を見ないので循環しないが、**教師ラベルが評価指標と同じ定義**である点は論文に明記する |

| **Lotus v1 との関係** | 本計画は Marigold V2 上で立てている。Lotus v1 でも同じ選別が効くかは別途測る価値がある（選別なしで +10.31% 出ていたので、上積みが見込める） |
