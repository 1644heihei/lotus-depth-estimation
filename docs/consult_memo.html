深度推定の精度向上 — 測定結果と方針の再検討

対象 Lotus（拡散型単眼深度推定） 評価 NYUv2 654枚 ・ Booster 228フレーム 更新 2026-09-02

ご相談したいこと

当初の方針（物体検出による深度推定の改善）は、測定により原理的に不可能と判明しました。 改善余地の上限が 2.1% しかありません。

その後、誤差の 55〜75% が大域的な低周波成分にあることを特定し、 そこに効く方向を 8 つ探索しましたが、 すべて「上限が小さい」か「先行研究に埋まっている」で閉じています。

方針の再設定についてご判断をいただきたく、探索結果と判断材料をまとめました。

01当初方針の否定 測定で確定

「YOLO で物体を検出し、その深度を事前情報として与える」路線について、 手法を作る前に達成可能な上限（Oracle）を測定しました。 物体領域を GT に置き換えたときに指標がどれだけ動くかを測る方法です。

測定値意味
完璧な物体深度予測器があった場合の改善2.1%事前設定した閾値 5% 未満
物体領域を完全に GT 化した場合19.2%余地の 9 割は「深度の値」ではなく「形状」
物体領域の誤差密度0.901.0 が平均。物体は誤差の集中点ではない
数ヶ月の学習実験の最良値 vs 公式モデル差 0.09%実質「何もしないのと同じ」

前提が誤っていた

公式 Lotus は bbox 内（0.0448）の方が bbox 外（0.0523）より精度が高く、 物体が多い画像でも精度は落ちていませんでした。 「物体領域が弱点だから事前情報を注入する」という出発点自体が、データに支持されていませんでした。

鏡面・透明面（Booster データセット）でも同様に測定し、対照実験で補正した正味の余地は 5.3% でした。局所的な手がかりでは届きません。

02誤差の所在の特定 再現確認済み

誤差を空間周波数で分解したところ、大域的な低周波成分が支配的でした。 2 データセットで一貫しています。

誤差の成分BoosterNYUv2
大域的な傾き（3 パラメータ）22.8%8.2%
大域的な 2 次成分36.4%18.9%
低周波成分の合計75.3%54.7%
局所的な手がかり（物体・材質）5.3%2.1%

局所的手がかりの 14〜26 倍の余地が大域成分にあります。 半年かけて追っていた方向が、余地の大きさで見て一貫して「小さい方」だったことになります。

ただし後処理では届きません 3 経路すべて閉塞

経路測定結果判定
固定バイアスを引く同符号率 58%、|平均|/σ = 0.11系統的でない
複数条件で推論して平均大域残差相関 0.67〜0.92、大域成分の削減 3.7%同じ間違いをする
出力から予測して補正R² = −0.79 / −0.50、適用すると 14.5% 悪化情報が無い

3 つ目はシーン単位の交差検証で測定しました（同一シーンのフレームは相関が高く、 通常の分割では過大評価されるため）。大域誤差を取るには、モデルの出力に無い情報が必要です。

03探索した 8 方向とその結末

誤差の所在を特定した後、そこに効く方向を順に探索しました。 各方向とも、手法を作り込む前に「上限の測定」または「先行研究の調査」で判定しています。 1 方向あたり数時間〜1 日で、作ってから失敗する事態は避けられています。

方向判定根拠
物体条件付け上限 2.1%Oracle 測定。閾値 5% 未満
タイル分割による高解像度化原理的に不成立全設定で −22.8〜−65.7%。切り出すと文脈が失われる
材質（鏡面・透明面）上限 5.3%対照実験で見かけの 9.3% の半分が否定された
後処理による大域補正3 経路すべて閉塞固定バイアス / 摂動平均 / 学習補正（R² < 0）
疎な深度点先行研究上限 43% と大きいが Marigold-DC（ICCV 2025）/ Marigold-SSD（2026）
平面拘束（床・壁）先行研究 + 部分問題なし上限 23〜29%。P3Depth（CVPR 2022）。
支持領域の IoU 0.35 で「位置は分かるが向きが違う」ではなかった

診断駆動の層配置仮説不成立今回実施。どの層に適応させても動くのは大域成分だった

直近の測定（診断駆動の層配置）

「UNet の深さは空間スケールに対応するので、粗い層に適応させれば大域成分が、 細かい層なら局所成分が動くはず」という仮説を検証しました。成立すれば 「壊れている成分を測定して適応先を決める」手法が組めます。 LoRA のパラメータ数を揃えて比較しています（0.96M vs 0.95M）。

適応した層全体大域成分局所成分より動いた成分
粗い層（mid + 24²）−4.51%−6.08%−2.62%GLOBAL
細かい層（96²）−12.91%−17.34%−7.57%GLOBAL
全層−12.11%−15.92%−7.51%GLOBAL

仮説は成立せず

高解像度層だけに適応させても、大域成分が 17.3% 悪化し、局所成分は 7.6% しか動きません。 拡散 UNet は残差接続で情報が全層を貫通するため、どこを触っても出力の低周波構造が変わると解釈できます。 配置が結果を左右すること自体は事実ですが（同パラメータ数で粗い層は細かい層の約 1/3 の害）、 成分を選択的に操作できるわけではなく、差別化になりません。

04先行研究との関係 主要部分は先行あり

大域誤差に効く情報として疎な深度点（LiDAR・SfM 等）を測定し、 20 点で 43%、100 点で 64.5% の改善を確認しました。これは有望でしたが、調査の結果:

項目先行研究状態
疎な点による depth completionMarigold-DC（ICCV 2025, ETH）先行
単一ステップ拡散 + zero-init + 疎な点Marigold-SSD（2026-05, DTU+ETH）設計がほぼ同一
補間ベースラインとの比較・疎度分析同上実施済み
誤差の affine / residual 分解PLOS Comput Biol 2025先行
「per-image affine が支配的」同上先行

設計の一致

Marigold-SSD は「単一ステップ拡散モデル + 疎な深度点 + zero-init 畳み込みで条件経路を初期化」 という構成です。これは本研究で計画していた設計と偶然ではなく、同じ制約から同じ結論として一致しています。 学習コスト 4.5 GPU 日、屋内 4 + 屋外 2 ベンチマークで評価済みです。

この分野は ETH Zürich・DTU 等が 2025〜2026 年に ICCV / ICLR / ICRA / TIP に連続して投稿しており、 Awesome-Foundation-Model-Based-Depth というキュレーションリストが存在するほど活発です。

05手元に残っている成果 検証済み

いずれも学習不要・GT 不使用で、対照実験とシーン別検証を通しています。

内容効果備考
processing_res の設定ミス修正+9.8%公式デフォルト 768 に対し 512 で実験していた。
過去の全実験が公式に不利な条件だった
多解像度アンサンブル+7.29%Booster。勝率 30/38、平滑化対照に合格
反転 TTA+2.64%NYUv2。勝率 66%
疎な点 + 補間+43%（20 点）先行研究あり（§3）

先行研究に見当たらない部分

  • 物体・材質条件付けの Oracle 上限の定量化（2.1% / 5.3%、対照実験付き）
  • 後処理 3 経路の到達不能性の実証（特に R² 測定による否定）
  • アンサンブルが消しているのは局所成分という分解（大域 3.7% vs 局所 21.5%）
  • 「なぜ疎な点が効くのか」を誤差構造から説明した点

ただしこれらはいずれも分析であり、手法ではありません。

06ご判断いただきたい点

A分析研究として構成する

誤差構造の解明と各介入の到達可能性の定量化を主貢献とする。手法は既存のものを使う。

必要作業
複数モデル（Depth Anything V2 等）への一般化。半日〜数日
想定発表先
MIRU / SSII / 国際会議ワークショップ
懸念
「調査研究では通らない」というご指導と衝突します
B別の追加情報を探す 探索済み

疎な点・平面拘束・診断駆動の適応を探索し、いずれも先行研究または仮説不成立で閉じました（§3）。 残るのは重力方向・複数視点などですが、探索コストに対して見込みが低いと考えます。

懸念
8 方向すべてが 1 回の調査で先行研究に当たっています。 分野の飽和度と論文の刊行速度から、次の案も同様になる確率が高いと見ています
C応用側に土俵を移す 要相談

深度推定そのものではなく、下流タスク側で新規性を出す。 「誤差は大域低周波」という測定が、どの応用が脆弱かを予測する武器になります。

ただし調査の結果、領域特化（内視鏡・水中・農業・サーマル・悪天候）は すべて 2024〜2026 に実施済みでした。 「基盤モデル + LoRA + ニッチ領域 = SOTA」というテンプレートが安価なため、 多くのグループが高速に埋めています。

前提
研究室に応用側の設備・データ・知見が無いため、ゼロから用意する必要があります
懸念
研究室のテーマ範囲に収まるか、残り期間で環境を用意できるか
D先行研究の限界を突く

Marigold-SSD が limitations に挙げている「学習時と異なる疎度での性能低下」など、 既知の弱点に絞って手法を作る。

必要作業
該当論文の再現と弱点の定量化
懸念
差分が小さくなりやすい

特にお伺いしたい点

  • 分析中心の構成（案 A）はどの程度まで許容されますか
  • 「学会発表」の想定先は国内会議でしょうか、国際会議本会議でしょうか
  • 応用側へのテーマ移動（案 C）は研究室の範囲内でしょうか
  • 残り期間から見て、新規の探索（案 B）に割ける時間はどの程度でしょうか
