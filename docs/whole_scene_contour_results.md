# シーン全体の輪郭による鋭化 — 結果

実施: 2026-09-08 〜 09-14
計画: [`whole_scene_contour_plan.md`](whole_scene_contour_plan.md)
前提: [`contour_sharpening_findings.md`](contour_sharpening_findings.md)

---

## 0. 結論

**物体検出をやめて画像全体を分割すると、鋭化の正味が 4 倍以上になる。**

| 輪郭の出どころ | 正味 |
|---------------|-----:|
| YOLO 物体マスク | −6.6% |
| SAM 物体マスク | +4.2% |
| **SAM 全体分割（grid 32）** | **+17.8%** |

被覆率を上げるほど単調に改善し、**輪郭の密度が高いほど良い**（grid 16 で +15.6%、32 で +17.8%）。
懸念していた「帯が広がって局所平滑化になる」現象は、輪郭が画素の 11.75% を占める密度でも起きなかった。

**ただし上限の 6.4% しか回収していない**（0.0763 対 0.2628）。
そして abs_rel は改善しない（−0.1%）。境界だけが良くなり、全体精度は横ばい。

---

## 1. なぜ全体分割か

鋭化の要求は 3 軸に分解済みで、**動かせる軸は被覆率だけ**だった。

| 軸 | 測定 | 含意 |
|----|------|------|
| **適合率** | 真の輪郭の 2 倍の偽輪郭を足しても −0.8pt | **過剰分割が罰されない** |
| **再現率** | ほぼ線形、5% の被覆でも +12.5% | ここを上げれば効く |
| 位置精度 | 1.71px を超えると利得が消える | 物体マスクは 2.00px |

適合率が無料なので、物体検出を捨てて画像全体を領域分割してよい。
そして被覆率こそが、物体検出を使う 7 方向すべてを閉じてきた原因だった。

## 2. 実装

```
物体経路:  YOLO の bbox → SAM（プロンプト付き）→ 物体マスク → 輪郭    1.66 個/画像
全体経路:  SAM automatic mode → 画像全体の領域分割 → 輪郭の和        99.7 個/画像
```

`transformers` の `pipeline("mask-generation")`。**fp16 は使えない**
（NMS が `dets should have the same type as scores` で落ちる）。fp32 で 3.74 s/画像、654 枚で約 36 分。

### 2 つの実装上の注意

**領域の和ではなく輪郭の和を取る。** 自動分割は画像をタイル状に覆うので、
**領域**の和を取ると画面全体が埋まり、内部の境界がすべて消える。
各領域の**輪郭**を和で重ねることで、隣接領域の共有境界が線として残る。

**下流は輪郭を二重に抽出しかねない。** 評価スクリプトは
「マスクの和 → `contour_of` で輪郭抽出」を前提とする。自動モードは既に輪郭を保存するので、
そのまま流すと 1 本の線が 2 本の平行線になる。
`--masks_are_contours` で明示的に分岐させた。

## 3. 結果

### G1 / G2 — 被覆率と位置精度（NYUv2 654 枚）

| | 物体マスク | **全体分割（32）** |
|---|--------:|-----------------:|
| **真の段差の 2px 以内を被覆** | 25.2% | **75.3%** |
| 真の段差 → 最近傍輪郭 中央値 | 37.64px | **1.00px** |
| 輪郭 → 段差 の位置精度 | 2.00px | 2.83px |
| 段差の無い輪郭画素 | 62.9% | 79.7% |
| 輪郭が占める画素 | 約 1% | 11.75% |

**G1 は 3 倍で圧勝。G2 は悪化したが、これは「輪郭 → 段差」方向で適合率の軸にあたり、
測定上は無料である。** 手法に効くのは逆方向で、真の段差の 75.3% が輪郭の 2px 以内にある。

### G3 / G4 — 鋭化の実測

| 輪郭の出どころ | BF1 | vs baseline | 移動対照 | **正味** | 上限回収 | abs_rel | n |
|---------------|----:|------------:|--------:|--------:|--------:|--------:|--:|
| YOLO 物体マスク | 0.0671 | −7.5% | 0.0718 | **−6.6%** | −2.4% | −0.1% | 521 |
| SAM 物体マスク | 0.0748 | +3.1% | 0.0718 | **+4.2%** | 1.5% | −0.2% | 521 |
| 全体分割（grid 16） | 0.0753 | +8.5% | 0.0644 | **+15.6%** | 5.6% | −0.2% | 654 |
| **全体分割（grid 32）** | **0.0763** | **+10.0%** | 0.0640 | **+17.8%** | **6.4%** | −0.1% | 654 |

baseline BF1 0.0693、完全な輪郭（GT）0.2628。

> **母集団の注意**: 物体マスクは検出のある **521 枚**、全体分割は **654 枚**で測っている。
> ベースライン自体が違う（0.0726 対 0.0693）ので、上表は厳密な同条件比較ではない。
> `--require_masks_in` を追加し、全体分割を同じ 521 枚に制限した値を別途測定中。

### 判定（着手前に固定）

| # | 条件 | 結果 |
|---|------|------|
| G1 | 被覆が 25.2% を明確に超える | **75.3%** ✅ |
| G2 | 位置精度が 2.00px 以下 | 2.83px ❌（適合率の軸なので無害） |
| G3 | 正味が +4.2% を超える | **+17.8%** ✅ |
| G4 | BF1 > 0.0693 かつ abs_rel 悪化なし | **0.0763** / −0.1% ✅ |

## 4. 読み取れること

**被覆率が律速だったという診断が正しかった。**
−6.6%（YOLO、被覆 18.8%）→ +4.2%（SAM 物体、25.2%）→ +17.8%（全体分割、75.3%）と単調。

**密度は高いほうが良い。** grid 16（50 領域）で +15.6%、grid 32（99.7 領域）で +17.8%。
計画のリスク 2（帯が広がって平滑化になる）は、この密度では現れなかった。
飽和点を探す価値がある。

**abs_rel は動かない。** 物体マスクのときに見えた +1.3% は消えた。
境界だけが改善し、深度の絶対精度は横ばい。
これは手法の位置づけを決める —— **abs_rel を改善する手法ではなく、境界を改善する手法**である。

## 5. 先行研究

スーパーピクセルによる深度マップ精緻化は 10 年以上の系譜がある
（[US 9292928](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/9292928)、
[Guided Depth Map Super-resolution: A Survey](https://arxiv.org/pdf/2302.09598)）。
**やっていることは近い** —— 領域に分割し、境界を越えないよう深度を埋め直す。
SLIC を SAM に置き換えた、と読まれるリスクがある。

SAM × 深度の最近の研究は方向が違う。
[BED-SAM2 (2026)](https://arxiv.org/abs/2605.24893) は深度で**分割を**改善し、
[RoSAMDepth (CVPR 2026)](https://openaccess.thecvf.com/content/CVPR2026/papers/Gao_RoSAMDepth_Robust_Self-supervised_Depth_Estimation_Leveraging_Segment_Anything_Model_CVPR_2026_paper.pdf)
は自己教師学習の平滑化拘束、
[Segment-Aware MDE (2026)](https://doi.org/10.3390/info17020145) は学習手法である。
**学習なしで既存の深度マップを分割境界で埋め直すもの**は見つかっていない。

新規性が主張できるとすれば 2 点。

1. **潜在拡散系の深度モデルへの適用。** スーパーピクセル系はステレオ・ToF・深度補完向けで、
   Marigold / Lotus のような VAE 由来の境界劣化を対象にしたものは見当たらない。
2. **要求の定量化。** 適合率が不要、再現率が線形、位置精度が 1.71px という
   3 軸の分解と閾値。手法というより測定の成果。
