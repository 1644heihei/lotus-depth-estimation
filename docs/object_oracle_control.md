# 物体Oracleの対照実験 — 2.1% の正体は「物体」ではなかった

実施: 2026-09-03
ブランチ: `feature/object-depth-aux-loss`
スクリプト: `eval_object_oracle_ceiling.py`(`--n_controls 3`)
評価: NYUv2 test 654枚, `processing_res=768`, Eigen crop

---

## 0. なぜ測り直したか

Phase 0 で「完璧な物体深度回帰器の上限は abs_rel 2.1%」と報告した。
しかしこの測定には**対照がなかった**。

Booster の材質 Oracle では、同じ面積・形状のマスクを無関係な位置にずらす対照を入れたところ、
見かけ 9.3% の利得のうち 4.0 ポイントが対照でも再現され、正味 5.3% まで落ちた。
「大域的にズレている予測に、どこであれ GT を入れれば低周波成分が部分的に直る」からである。

物体 Oracle にも同じ対照が必要だった。

---

## 1. 対照の設計

各画像で、YOLO の bbox / seg マスクを **円環シフト**（`np.roll`, 縦横それぞれ画像サイズの 20〜80%）
で無関係な位置へ移動し、同じ Oracle 操作を適用する。

- 面積・形状・個数は完全に同一
- 物体との対応だけが壊れる
- シフト量は毎回ランダム、**3 回の平均**（対照自体が当たり外れにならないように）

したがって「実際の位置 − ずらした対照」だけが**物体であることに帰属できる利得**である。

---

## 2. 結果

baseline abs_rel = 0.05000

| Oracle | 実際の位置 | ずらした対照 | **正味** |
|--------|-----------:|-------------:|---------:|
| **A bbox**（深度レベルのみ補正 = 完璧な回帰器の上限） | 2.15% | **2.75%** | **−0.60%** |
| A mask（seg マスク内でレベル補正） | 3.13% | 2.76% | **+0.37%** |
| B bbox（bbox 内を GT で全置換） | 19.17% | 15.26% | +3.91% |
| B mask（seg マスク内を GT で全置換） | 13.23% | 10.68% | +2.55% |

参考: BG（物体の外側を全置換）= 80.8%

---

## 3. 何が言えるか

### 3.1 A_bbox は対照を下回った

**当初の研究方針そのもの**（YOLO で物体を検出し、その領域の深度を先に推定して条件として与える）の
上限が、物体と無関係な場所に同じ大きさの矩形を置いた場合を**下回る**。

物体であることの寄与は**測定できるレベルでゼロ**である。

### 3.2 利得の正体は大域誤差

対照でも 2.75% 出るのは、[`global_error_findings.md`](global_error_findings.md) の分解と整合する。
NYUv2 の誤差の 54.7%（Booster では 75.3%）は低周波の大域成分で、
予測全体が緩やかにズレている。そこへ **面積 A の領域に GT を入れれば、
その領域が何であれ**大域成分が部分的に打ち消される。

つまり Oracle A が測っていたのは「物体を直す効果」ではなく
「画像の 2 割弱の面積に正解を差し込む効果」だった。

### 3.3 「間違っていない情報を足すのになぜ下がるのか」への答え

情報が誤っているのではない。**物体固有の情報になっていない**。

bbox の大小から遠近を推定するといった手がかりは、モデルが既に持っており、
そこは壊れていない（局所成分は誤差の 45%、うち物体領域固有の分はこの測定では検出されない）。
一方、条件付けを学習させると fine-tune 税が確実に乗る
（[`adaptation_placement_findings.md`](adaptation_placement_findings.md): 同一パラメータ数で −4.6〜−12.6%）。

**得るものが 0、払うコストが 5〜13% なので、下がる。** 実測の劣化と一致する。

### 3.4 B（全置換）にはまだ正味が残る

B_bbox の正味 +3.9%、B_mask の正味 +2.6% は、
物体の**形状・境界**（レベルではなく高周波側）にまだ物体固有の情報があることを示す。
ただしこれは「物体領域の深度を完全に知っている」場合の上限であり、
レベル補正型（A）では取り出せない。回帰器では届かない領域である。
