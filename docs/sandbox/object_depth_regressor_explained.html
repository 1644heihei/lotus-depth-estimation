なぜ Step 1 が90秒で終わる？
画像をUNetに通していません。CSVの数値行（約9万行）を小さなMLPに入れるだけです。 Lotus detail 学習（数万step）とは計算量が桁違いに小さいです。

5. ベースライン（比較用の単純モデル）

MLP が「ちゃんと学習する価値があるか」を見るための下限・参照です。

名前やっていること比喩
Global median 全部の物体に同じ深度（≈37m）を返す 「とにかく平均を言う」
Per-class median クラスごとの典型深度を返す（サイズは無視） 「椅子ならだいたい2m」
Linear class + サイズを直線でフィット 「MLPより単純な学習」
MLP class + サイズを非線形でフィット 「今回の本命」

6. abs_rel と δ1 — 入力が数値でも深度同士の比較

Step 1 では物体1個 = 深度スカラー1個。評価は「予測深度 vs GT深度」の近さです。画素ではありません。

abs_rel = mean( |pred − gt| / gt ) ← 平均的に何%ズレてるか（小さいほど良い） ratio = max(pred/gt, gt/pred) δ1 = ratio < 1.25 の物体の割合 ← ±25%以内に収まった物体の%
評価の種類1サンプルδ1 の意味
Step 1（物体単位） 物体1個 「物体の何%が深度±25%以内か」
Step 2（画像単位） 画素1個 「画素の何%が深度±25%以内か」（Lotus標準）

7. Step 2 — pre-depth を作って Lotus に渡す

MLP が出した物体ごとの深度1個を、画像上の bbox 内に定数で塗り、Lotus の global 深度と融合します。

① Lotus global 深度
② MLP深度を bbox 内に塗る
③ lstsq 整合 + 融合 → pre-depth
  1. Lotus-D(RGB) で global disparity マップを取得
  2. 各 bbox: MLP → depth [m] → disparity → bbox 内を同じ値で塗る
  3. global にスケール合わせ（lstsq）して pre-depth 画像を完成
  4. 9ch 詳細 Lotus（RGB + pre-depth + valid mask）で最終深度推論
Step 2 の評価はNYUv2 654枚全体の abs_rel / δ1（Lotus標準プロトコル）。 smoke test（10枚）では abs_rel ≈ 0.093 でしたが、本番654枚は未実行です。
