## 0. 結論

**成功した。生の BF1 増分 11.92% ± 0.90%（seed 4 本）、4 本すべてが成功基準（+10%）を超えた。**

```
生の BF1 増分  11.92% ± 0.90%  (n=4)
95% 信頼区間   [10.49%, 13.35%]   <- 下限も +10% の上
範囲           10.75% 〜 12.74%
```

以下の表は seed 42（代表値）。seed 間の分散は §1.5 に記す。

| 選別 | 残存 | BF1 | 生 | 移設対照 | abs_rel |
|---|---:|---:|---:|---:|---:|
| baseline（鋭化なし） | — | 0.0884 | — | — | 0.03881 |
| 選別なし（全輪郭） | 100% | 0.0867 | −1.90% | −6.22% | 0.03898 |
| 画素ランダム | 3.95% | 0.0704 | −20.35% | −2.23% | 0.03887 |

**abs_rel も改善している**（0.03881 → 0.03860、−0.5%）。境界を精度と交換していない。

## 1. 学習器

| | |
|---|---|
| 構造 | U-Net 4 段、base 32ch、**1.93M パラメータ** |
| 入力 | 5ch（RGB 3 ＋ 予測深度 1 ＋ 輪郭マスク 1） |
| 出力 | 1ch のロジット |
| 損失 | **輪郭画素だけに掛けるマスク付き BCE**（画像の 88% は寄与しない） |
| 学習データ | NYUv2 train 795 枚をシーン単位で分割 → train 654 / val 141（40 シーン） |
| 学習時間 | **16 分**、40 epoch、ピーク VRAM **3,507 MiB** |
| 評価 | NYUv2 test 654 枚。**train とシーン重複ゼロ** |

予測深度は**画像ごとに標準化**して入れる。`Log-stage2` はアフィン不変 log depth を出すので
絶対値と尺度に意味がなく、学習時と推論時で揃えないと壊れる。

### 適合率は val と test で一致した

| | 適合率 | 再現率 | ベース比 |
|---|---:|---:|---:|
| val（epoch 17、最良） | 49.2% | 48.7% | — |
| **test** | **50.2%** | 49.6% | **8.3×** |
| test・閾値（学習ゼロ） | 32.8% | 35.9% | 5.4× |

**「40 epoch から val で選んだので楽観側に偏る」という懸念は実現しなかった。**
epoch 17 が最良で、以降は 46.4% に低下（過学習）したが、選んだ重みは test で 50.2% を出した。

## 1.5 seed 間の分散（n=4）

seed は**モデルの初期化・データ順序・train/val のシーン分割**を同時に変えるので、
得られるのは実行間の総分散である。

| seed | val 適合率 | test 適合率 | BF1 | 生 | abs_rel |
|---:|---:|---:|---:|---:|---:|
| 42 | 49.2% | 50.2% | 0.0994 | +12.49% | 0.03860 |
| 1 | 43.3% | 49.8% | 0.0987 | +11.69% | 0.03862 |
| 2 | 47.5% | 50.4% | 0.0996 | +12.74% | 0.03861 |
| 3 | 48.4% | 50.6% | 0.0978 | +10.75% | 0.03862 |
| **平均** | 47.1% | **50.2%** | **0.0989** | **+11.92%** | 0.03861 |
| 標準偏差 | 2.6 | **0.3** | 0.0008 | **0.90** | 0.00001 |

**4 本すべてが個別に +10% を超え、95% 信頼区間の下限も +10% の上にある。**
成功基準の達成は単一実行の幸運ではない。

abs_rel は 0.03861 ± 0.00001 で、4 本すべてが baseline 0.03881 を改善している。

### val 適合率は当てにならない推定値である

```
val  適合率  47.1% ± 2.6     <- ばらつく
test 適合率  50.2% ± 0.3     <- ほとんど動かない
```

**test の方が 9 倍安定している。** val は 40 シーン 141 枚なので「どのシーンが選ばれたか」に
左右されるが、test は 215 シーン 654 枚で固定である。

seed 1 は val 43.3%（4 本中最低）でありながら test では 49.8% を出した。
**ノイズの多い val でチェックポイントを選んでも test 性能は損なわれない。**
§1 で懸念した「40 epoch から val で選ぶと楽観側に偏る」は 4 本すべてで起きなかった。

## 2. 換算式は 3.5pt 過小予測した

[`contour_selector_plan.md`](contour_selector_plan.md) §2.5 の式

```
生の BF1 増分 ≈ 0.69 × (適合率 − 37.1%)
```

| | 適合率 | 換算 | 実測 | 差 |
|---|---:|---:|---:|---:|
| 学習した選別器 | 50.2% | +9.0% | **+12.49%** | **+3.5pt** |
| 閾値（学習ゼロ） | 32.8% | −3.0% | −2.07% | +0.9pt |

式はランダム（散らばった選択、適合率 7.6%）とオラクル（完璧、100%）の 2 点で引いた。
**学習した選別器は、同じ適合率のランダムより良い。**

偽陽性が真の段差から 1〜2px 外れた近傍に集まっており、無関係な模様を選ぶランダムより
損害が小さいためと考えられる。

**適合率は支配的な要因だが唯一ではない。誤りの空間構造も効く。**

## 3. 対照が何を確立しているか

学習が仕事をしていることは、4 つの対照すべてが負であることで示される。

| 対照 | 生 | 排除するもの |
|---|---:|---|
| 移設（同じ疎さ・違う場所） | −0.50% | **疎であること自体** |
| 画素ランダム（同率） | −20.35% | 無技能選別 ＋ 連続性の欠如 |
| ブロックランダム（同率） | −1.48% | 構造を保った無技能選別 |
| 閾値（学習ゼロ、AUC 0.876） | −2.07% | **手作り特徴で届く範囲** |

**学習ゼロで到達できる最良が −2.07% で、学習して +12.49%。**
14.6pt の差がそのまま学習の寄与である。

## 4. 小成分除去は逆効果だった

| | 残存 | 生 |
|---|---:|---:|
| 選別器のみ | 6.00% | **+12.49%** |
| ＋ 小成分除去（20px 未満） | 5.00% | +8.61% |

[`contour_selector_plan.md`](contour_selector_plan.md) §1.5 の連続性制約
（画素ランダムが −20.35%）への備えとして入れたが、**CNN の出力は既に十分連続で、
除去は有用な選択を捨てていた**。畳み込みが構造上なめらかという想定が正しかったということである。

両方測ったので分かった。**制約への対処を測らずに入れると 3.9pt 損する。**

## 4.5 Hypersim への転移は失敗した（2026-09-28）

NYUv2 のみという限界を潰すため、NYUv2 で学習した選別器を**無変更で** Hypersim
hold-out 300 枚に適用した。`utils/eval_frames.py` を新設し、採点経路は分岐させずに
データセット切り替えだけを足した（NYUv2 の +12.49% が完全再現することを回帰テストで確認済み）。

| 条件 | BF1 | 生 | 対照 | abs_rel | delta1 |
|---|---:|---:|---:|---:|---:|
| baseline | 0.2678 | — | — | 0.15668 | 0.79226 |
| 選別なし（全輪郭） | 0.2739 | **+2.28%** | −8.27% | 0.15682 | 0.79203 |
| 学習した選別器 | 0.2554 | **−4.64%** | −0.74% | 0.15674 | 0.79210 |
| オラクル上限 | 0.3736 | +39.49% | — | 0.15594 | 0.79315 |

**選別なしの方が良い。** 予測は +8〜15% だったので大きく外した。

### 原因は適合率ではなく残存率の設定

```
適合率  55.8%    <- NYUv2 の 50.2% より高い
再現率  14.7%    <- ここが問題
正例率  22.81%   <- NYUv2 は 6.07%
```

Hypersim は GT が合成で厳密なため、**輪郭の 22.81% が本物の段差**である（NYUv2 の 3.8 倍）。
そこへ NYUv2 用の残存率 6% を当てたので、

```
再現率の上限 = 6 / 22.81 = 26%   -> 実測 14.7%、本物の 85% を捨てている
```

**選別器は正しく選んでいるが、選ぶ数が足りない。** 全輪郭を使う方が良いのは当然である。

換算式（§2）も +12.9% と予測して 17pt 外した。**あの式は正例率 6.07% で校正したもの**であり、
正例率が 3.8 倍違う条件では成立しない。**残存率は正例率に合わせて決める必要がある。**

### より重い交絡 — Hypersim は Marigold V2 の学習データである

`hypersim_holdout.json` は Lotus の実験用に作った分割であり、**Marigold V2 の学習分割とは
無関係**である。Marigold V2 の Stage 1 / Stage 2 はいずれも Hypersim ＋ vKITTI で学習されており、
この 300 枚を見ている可能性が高い。

これが baseline BF1 0.2678（NYUv2 の 3 倍）と、オラクル上限がわずか +39.49%
（NYUv2 は +209.8%）の理由だと考えられる。土台が既に上手くやっているので直す余地が小さい。

**したがってこの結果は、残存率を直したとしても「別データセットでも成立する」の証拠にはならない。**
汎化の検証には、Marigold V2 の学習に使われていない評価データが必要である。
KITTI / ETH3D / DIODE は分割定義のみで評価データ自体が手元に無い。

## 5. 正直に述べる限界

| | 内容 |
|---|---|
| **上限の 71% が未回収** | オラクル +43.39% に対し +12.49%。適合率 50.2% を上げる余地が残る |
| **NYUv2 のみ** | 学習も評価も NYUv2。train/test はシーン重複ゼロ。**Hypersim への転移を試みたが失敗し（§4.5）、しかも在ドメインのため汎化の検証にならなかった。**Marigold V2 の学習に使われていない評価データが必要 |
| **ラベルと指標が同一定義** | 教師は「GT の段差から 1px 以内」、BF1 も GT の段差との一致を測る。推論時に GT は使わず test シーンも別だが、**論文にはこの対応関係を明記する** |
| **学習データ 795 枚** | シーン多様性が小さい。輪郭画素では 1,750 万あるが画素は独立でない |
| ~~単一 seed・単一実行~~ | **解消**（§1.5）。seed 4 本で 11.92% ± 0.90%、全本が基準超え |
| **Lotus v1 では未検証** | 同じ選別器が Lotus v1 でも効くかは別途測る価値がある（選別なしで +10.31% 出ていたので上積みが見込める） |

## 6. 予測の記録

このセッションで 3 回予測し、**3 回とも悲観側に外した**。

| 予測 | 実測 |
|---|---|
| 学習ゼロの閾値選別器: +5〜15% | **−2.07%**（楽観側に外した唯一の例） |
| 選別器の val 適合率: 40〜45% | **49.2%** |
| 端から端までの生の BF1: +5〜8% | **+12.49%** |

AUC を適合率に換算せずに楽観したのが 1 つ目の原因。
2 つ目と 3 つ目は、空間文脈の寄与を過小評価していた。
